# Product & UX Direction

## Positioning
The experience should feel established, trustworthy and examination-focused. Students should immediately recognize the interaction model used by serious Indian mock-test platforms.

## Inspiration rule
Use common conventions such as:
- exam selection
- test cards
- test instructions
- language selection
- question palette
- timer
- mark for review
- result summaries
- sectional/topic analysis
- history and performance dashboards

Do not copy proprietary code, logos, brand identity, exact copy or pixel-level layouts.

## Visual direction
- premium and understated
- strong neutral surfaces with purposeful accent color
- excellent typography
- moderate radii
- disciplined spacing
- restrained decoration
- limited animation
- desktop/mobile parity
- no fake AI sparkle language

## Home
Clearly communicate:
- what the platform is
- supported exams
- free mock-test proposition
- exam discovery
- featured tests
- preparation resources
- trust/credibility signals

## Test discovery
Every test card communicates:
- exam
- stage
- test type
- question count
- duration
- marks
- negative marking
- available languages
- attempt CTA

## Before test
Formal instruction screen with:
- test name
- pattern summary
- sections
- language selector: English / हिंदी / मराठी
- questions
- marks
- duration
- negative marking
- navigation rules
- start button

## Active test
Prioritize speed and familiarity:
- persistent timer
- clear question number
- uncluttered options
- question palette
- answered/unanswered/marked states
- mark for review
- save & next
- previous
- clear response
- guarded submit

## Results
Show:
- score
- attempted
- correct
- incorrect
- unattempted
- accuracy
- time

Then:
- section analysis
- topic analysis
- answer review
- explanations
- weak areas
- recommended practice

## Dashboard
Prioritize actions:
- continue test
- start new mock
- review last attempt
- weak topics
- history
- progress trends

## Accessibility
Visible focus states, descriptive labels, sufficient contrast, touch-friendly controls, and status communication that does not rely on color alone.
